## 1. Projector Room Butcher

**Lane:** GRITTY BOOM BAP x CINEMATIC HORROR

**Vibe:** Basement-tape boom bap shot like a horror film. The loop is dusty and swung, but the percussion is built out of objects instead of a drum kit.

**From the Noises doc:** Prepared piano (as gunmetal percussion), typewriter keys (hi-hat replacement), zippo flick (snare ghost layer), old film projector, vinyl crackle, bassoon, tubular bells (one hit per 8 bars), spent shell casings, gang chant pitched down an octave, deep pitch-dropped ad-libs, glitch reverb, reverse reverb, tape stop.

**Beat notes:** 88–96 BPM, behind-the-beat sampler swing. Snare is a rim-click stacked with a lighter flick. No 808 — the low end is a filtered sample bass. Tubular bell is the only 'big' sound, so it lands like a punctuation mark.
