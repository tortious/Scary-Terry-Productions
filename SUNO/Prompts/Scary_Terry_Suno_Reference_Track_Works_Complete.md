- These boxes prioritize **genre/subgenre → BPM/feel → drum architecture → bass behavior → instrumentation → atmosphere/foley → vocal delivery → mix traits**, matching the project Style Box workflow.
- Where a reference song is famous for very fast or chaotic delivery, the production DNA is preserved but the vocal prompt is intentionally kept **articulate, controlled, and non-rushed** because the project exclusions require `speed rap` and `fast delivery` to be excluded.
- For tracks with double-counted tempos, both the DAW/grid tempo and the practical half-time feel are shown when useful.
- `Original style retention` is highest on Option 1, lower on Option 2, and lowest on Option 3 so the third option can function as a genuine transformation rather than a near-cover.
