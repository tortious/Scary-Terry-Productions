# Suno v6 Style Boxes — Darkly Melancholic Catchy Trap

Here are **10 Suno v6 style boxes** engineered for a darkly melancholic, catchy trap brief — each paired with its own exclusion box. The style prompts stay within v6 guidance of roughly **10–15 focused descriptors** so the model does not dilute the mood. The exclusion boxes list **positive elements to block** (not “no…” phrasing) because Suno's exclude field works as a negative prompt.

## Quick-use note

- **Style box** → paste into “Style of Music.” Keep it sound-only; no story or lyric lines.
- **Exclude Styles box** → paste into “Exclude Styles” under More Options. This is the only reliable negative path in v6.
- **Vocal gender** can be reinforced in the Exclude box if Suno drifts (e.g., exclude “female vocals” if you want a male lead).

## v6 settings to pair with these boxes

- **Variety:** set to **Off** when the style box is engineered — this stops Suno from rewriting your tags.
- **Max Mode:** recommended for consistency across a full song, especially if your lyrics are dense and multisyllabic.
- **Tempo:** the BPM in each box is a starting point; if the track feels sluggish, the half-time feel may need clarifying in the prompt.
