## 1. The "Random Noise" Dictionary (Ear Candy)

When searching for samples or describing sounds to an AI, use these official industry terms:

| Category   | Sound Name          | Description                                                      |
|------------|---------------------|------------------------------------------------------------------|
| **Twinkles** | Arp Runs           | Rapid-fire shimmering notes that sound like a digital staircase. |
|            | Chime Glissando     | The classic "magical" sparkle heard in transitions.              |
|            | Crystal/Bell One-Shot | Short, resonant hits that sound like glass or high-end jewelry. |
| **Lasers** | Zaps                | Short, downward-pitch-shifting "pew pew" sounds.                 |
|            | 8-Bit Blips         | Retro video game noises (coin collects, power-ups).              |
|            | FM Chirps           | High-pitched, digital "computer" noises often found in Glitchcore. |
| **Grimy**  | Phonk Cowbell       | The "Memphis" metallic clink that defines dark, upbeat trap.     |
|            | Industrial Hits     | Clanging metal, steam hisses, or heavy machinery used as drums.  |
|            | Detuned Bells       | Eerie, "sour" sounding bells used in horror-trap.                |
| **Textural** | Bubble Pops       | "Wet" plucking sounds common in Bubblegum Bass.                  |
|            | Foley Hits          | Real-world sounds (keys, staplers, light switches) used as percussion. |

### Style Box Tags
- `Rhythmic 'Hey' Vox`

3. Optimized Suno Style Boxes (March 2026)
A. The “Bright & Poppy” (Laser / Twinkle Vibe)
Upbeat Pop-Rap, Bright Kawaii Future Bass, Digital Ear Candy, High-pitched Synth Plucks, Staccato Rhythm, Syncopated Pocket Flow, 8-bit blips, Crisp Snaps, Sparkling Arpeggios, Bubblegum Bass, High-Energy, Polished, Bouncy.
B. The “Haunting & Grimy” (Scary Terry Thug Vibe)
High-Energy Dark Trap, Haunting Detuned Bells, Phonk Cowbells, Grimy Industrial Textures, Aggressive 808 Slides, Eerie Sine Whistle, Distorted Choir Hook, Staccato Rhythm, Double-time Hi-Hats, Glitchy Ear Candy, Sinister, Bouncy, Evil, Polished.
C. The “Cyber-Trap” (Heavy Glitch Vibe)
Cybernetic Trap, Glitchcore, Metallic Laser Zaps, Hard-hitting 808s, Digital Chirps, High-passed White Noise Sweeps, Rhythmic Vocal Chops, Rapid-fire Percussion, Neon Synth Leads, Gritty, Mechanical Ear Candy.

4. Defining “Bubblegum Bass”
Bubblegum Bass is the “plastic” foundation of Hyperpop. It is essential for the “bright poppy” sound.
	•	Vibe: Sweet melodies mixed with aggressive, distorted bass.
	•	Key Sounds: “Latex” textures, rubbery snaps, and high-pitched vocal chops.
	•	Why for Scary Terry: It is minimalist and clean, making it the perfect backdrop for a high-speed Pocket Flow.

5. Pro-Tips for “Pocket Flow” Cadences
To ensure the AI doesn’t drown out your lyrics with a “wall of sound”:
	•	Use “Staccato” → Forces the instruments to be short and punchy.
	•	Use “Percussive Silence” → Tells the AI to leave “holes” in the beat.
	•	Use “Minimalist Trap Bounce” → Keeps the drums simple so your flow stays the focus.
